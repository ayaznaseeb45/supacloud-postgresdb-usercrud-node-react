# Supabase Practice

Express backend in `userbacked`.

## Run locally

Create `userbacked/.env` containing `PORT=5000` if it does not already exist.

```powershell
cd userbacked
npm ci
npm start
```

Set `PORT` in your local `.env` if needed (default: 5000).
Visit `http://localhost:5000/` to check the API.

Local `.env` files and dependencies are excluded from Git. Keep real credentials in your local environment.
